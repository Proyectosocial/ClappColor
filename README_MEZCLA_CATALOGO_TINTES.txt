COLORLAB - MEZCLA A+B CONECTADA AL CATALOGO

Cambios:
- El catálogo puede enviar cada tono al Color A o al Color B.
- Botones rápidos desde el Laboratorio para elegir A o B en el catálogo.
- La mezcla A+B calcula el HEX en tiempo real.
- El resultado busca el color más cercano entre los 1.176 tonos y muestra nombre/código.
- Se genera una preparación de entonadores para 1, 4, 10 o 20 litros.
- Si A y B tienen receta exacta cargada, combina ambas fórmulas según el slider.
- Si un color del catálogo no tiene fórmula exacta, usa la receta ColorLab cromáticamente más cercana y marca la preparación como ORIENTATIVA.

IMPORTANTE:
Los 1.176 colores técnicos contienen HEX/RGB, pero no fórmulas comerciales reales de pigmentos. Las preparaciones aproximadas deben calibrarse físicamente antes de fabricar pintura. Al cargar fórmulas oficiales por código, el mismo motor puede trabajar con recetas exactas.
