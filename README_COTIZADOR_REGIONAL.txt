COLORLAB - COTIZADOR REGIONAL

Integra Zona + Servicio + m2/días + mínimo + precio sugerido + máximo.
CABA se usa como base y las demás zonas aplican coeficientes editables en app.js (COLORLAB_ZONE_FACTORS).
El precio sugerido prioriza el tramo ARS 5.000-12.000 cuando el rango del servicio/zona lo intersecta.
CONTINUAR guarda window.COLORLAB_SERVICE_QUOTE y emite colorlab:serviceQuote para enlazar presupuesto/PDF.
Los valores son orientativos y no constituyen tarifas oficiales.
