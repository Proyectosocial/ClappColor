COLORLAB - LABORATORIO DE COLOR UNIFICADO

Cambios de esta versión:
- Fusiona "Color Tonal y Recetas" + "Mezclador General (2 Colores)" en una sola tarjeta responsive.
- Escritorio: dos columnas (buscador tonal + mezclador visual).
- Móvil/tablet: paneles apilados sin superposición.
- El Color A encontrado por nombre, código o HEX actualiza automáticamente el envase A del mezclador.
- El slider recalcula en tiempo real la mezcla con Color B y muestra el HEX resultante.
- Soporta búsqueda en Recetas ColorLab, Catálogo técnico de 1.176 colores o ambos.
- La receta de entonadores muestra ml y porcentaje calculado para el volumen elegido.
- Mantiene el catálogo técnico, Pintar una foto, cotizador, presupuesto formal, PDF, monetización y logo integrado.

- index.php
- estilos.css
- app.js

No se modificó el esquema SQL ni las funciones de API existentes.
